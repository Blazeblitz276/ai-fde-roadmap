Background job / worker

Work done outside the user's request by a separate process that pulls from a queue.

Used in: Rate limiting and background jobs
Backpressure

A signal that pushes back on producers to slow down when consumers are full.

Used in: Rate limiting and background jobs
BASE

Basically Available, Soft state, Eventually consistent: the scale-first alternative.

Used in: Choosing a database
Base model

The general model before your customisation.

Used in: Fine-tuning vs prompting vs RAG
Baseline

How the task performs today without the new system; what you compare against.

Used in: FDE craft: customer discovery and scoping a pilot
Batch API

A provider endpoint that runs many requests offline at a discount with slower turnaround.

Used in: LLM serving cost and latency
Batch inference

Running predictions on many stored items at once on a schedule.

Used in: Computer vision in production
Bean (Spring)

An object created and managed by the Spring container.

Used in: Code-level design patterns
Bearer token

Whoever holds it can use it, so it must be short-lived and sent only in HTTPS headers.

Used in: OAuth 2.0 and OpenID Connect
Big ball of mud

Code with no clear structure where everything depends on everything.

Used in: Hexagonal architecture and SOLID
Blameless postmortem

A written review that focuses on system and process fixes, not on blaming people.

Used in: SLOs, error budgets and incidents
Blast radius

How much damage one failure or compromise can cause.

Used in: Cloud IAM across AWS, Azure and GCP
BM25

Classic keyword-ranking formula that scores documents by matching words, weighting rare words more.

Used in: Improving RAG
Break-glass

A controlled emergency process to bypass the normal pipeline.

Used in: CI/CD and infrastructure as code
Breaking change

A change that makes existing clients fail (removing or renaming fields).

Used in: API design: REST, GraphQL, gRPC
BSL / OpenTofu

Terraform's 2023 source-available licence / the open-source community fork.

Used in: CI/CD and infrastructure as code
Budget

A spend target that triggers alerts (and optional actions) at thresholds.

Used in: Cloud billing and cost control for AI apps
Budget cap

A hard limit on steps, agents, tokens or money for a run.

Used in: Agent memory and multi-agent orchestration
Budget owner / sponsor

The person who can approve money and production rollout.

Used in: FDE craft: customer discovery and scoping a pilot
Bulkhead

Isolating resources per dependency so one can't exhaust all (part 2).

Used in: API gateway, circuit breaker, retry with backoff
Bundle

In OKF, a folder of concept files shipped together (e.g. a git repo).

Used in: Beyond classic RAG
Burn rate

How fast the error budget is being used compared with an even spend.

Used in: SLOs, error budgets and incidents
Burst

A short spike above the steady rate.

Used in: Rate limiting and background jobs
