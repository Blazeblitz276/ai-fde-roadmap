Glossary: E

ECS / ECS Express Mode

AWS's container orchestrator; Express Mode creates a full app stack (Fargate service, load balancer, auto scaling) from one image.

Used in: Serverless containers
Edge

Computing on or near the device that produces the data, not in a cloud data centre.

Used in: Computer vision in production
Edge middleware

Small code that runs on CDN servers close to users before a request reaches your app.

Used in: Hosting an AI-built Next.js + Python app
Egress

Data leaving the cloud or a region; usually charged.

Used in: Cloud billing and cost control for AI apps
EKS

Amazon's managed Kubernetes (drop 5).

Used in: Evaluating and monitoring AI agents
Elixir / Erlang VM

A language and runtime built for huge numbers of lightweight concurrent processes.

Used in: Load balancing and consistent hashing
ELK

Elasticsearch, Logstash, Kibana: a popular self-hosted logging stack.

Used in: Logging and monitoring
Embedding

A list of numbers representing the meaning of text; similar meanings give nearby vectors.

A vector of numbers representing meaning, produced by a model.

Used in: Caching in LLM and RAG apps Embeddings and vector databases
Embedding / vector search

Turning text into a list of numbers that captures meaning, and finding chunks with similar numbers.

Used in: Improving RAG
Embedding distance

How far new images sit from training images in the model's feature space.

Used in: Computer vision in production
Endpoint

A hosted URL that runs a model on request.

Used in: Computer vision in production
Entra ID

Microsoft's identity directory, formerly Azure Active Directory.

Used in: Cloud IAM across AWS, Azure and GCP
Entra ID / managed identity

Microsoft's identity directory / an identity Azure gives your app so it needs no stored secret.

Used in: MCP: the USB-C port for AI tools
Envoy

Open-source proxy created at Lyft, the most common sidecar proxy.

Used in: Bulkhead, sidecar, strangler fig and saga
Error budget

1 - SLO: the amount of failure you are allowed in the window.

Used in: SLOs, error budgets and incidents
etcd

The small database where Kubernetes stores the desired and current state.

Used in: Kubernetes: GKE vs EKS vs AKS
Eval (evaluation)

A repeatable test that scores an AI system's outputs.

Used in: RAG evals
Eval set (golden set)

A fixed list of test questions with expected answers used to measure quality.

Used in: Fine-tuning vs prompting vs RAG
Evals

Automated tests of model or agent quality on a fixed set of examples.

Used in: Bedrock vs Microsoft Foundry vs Google's Agent Platform
Event

A message stating a fact that already happened, named in past tense (OrderPlaced).

Used in: Pub/sub, event-driven architecture and CQRS
Event sourcing

Storing every change as an event and deriving current state by replaying them.

Used in: Pub/sub, event-driven architecture and CQRS
Event store

The database that holds the event history.

Used in: Pub/sub, event-driven architecture and CQRS
Eventual consistency

Data across services may disagree briefly but converges to the correct state.

Copies of data agree after a short delay, not instantly.

Copies may disagree briefly but converge if writes stop.

Used in: Bulkhead, sidecar, strangler fig and saga Pub/sub, event-driven architecture and CQRS Choosing a database
Eviction, LRU, LFU

Removing entries when full; least recently used; least frequently used.

Used in: Caching in a real system
Exfiltration

Secretly sending stolen data out of a system.

Used in: LLM guardrails and prompt injection
Exponential backoff

Waiting longer after each failure (e.g. doubling).

Used in: API gateway, circuit breaker, retry with backoff
Exponential backoff / jitter

Waiting longer after each failure / adding randomness to the wait.

Used in: API design: REST, GraphQL, gRPC
